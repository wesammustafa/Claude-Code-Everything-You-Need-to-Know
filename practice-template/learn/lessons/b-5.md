## ladder

### a committed CLAUDE.md has a rule that every new JavaScript file in `src/` starts with a given line
- narrow "There is no committed CLAUDE.md.": Has the reviewed project instruction file been committed?
- narrow "has no line like": Does the committed instruction name the required header line?
- narrow "doesn't say which files": Is the header rule limited to source JavaScript files?
- back: W2 Revisit the decision and evidence from this step before trying the same action again.

### a commit made after that rule adds JavaScript files to `src/`, and each of them starts with the rule's line
- narrow "Commit a CLAUDE.md": Was the rule committed before requesting a new source file?
- narrow "git has no commit": Can git find the commit that introduced this rule?
- narrow "these new files are not committed yet": Did the new session commit the source file it created?
- narrow "In a new session, ask for a change": Did a later session add a new source file after the rule?
- narrow "these new files don't start": Does the first line of each added source file match the rule?
- back: W3 Revisit the decision and evidence from this step before trying the same action again.

### the committed CLAUDE.md holds the notes' rule for CLI errors, and every `npm run` script it names is in `package.json`
- narrow "There is no committed CLAUDE.md.": Has the reviewed project instruction file been committed?
- narrow "doesn't have the rule": Is the verified CLI error convention in the shared instructions?
- narrow "package.json doesn't parse": Can the project configuration be parsed before checking its scripts?
- narrow "but package.json has no such script": Does this instruction name a script that actually exists?
- back: Y1 Revisit the decision and evidence from this step before trying the same action again.

### a committed `.gitignore` keeps `CLAUDE.local.md` out, git tracks no `CLAUDE.local.md`, and the committed CLAUDE.md holds neither personal note
- narrow "There is no committed CLAUDE.md.": Has the reviewed project instruction file been committed?
- narrow "git tracks": Is the personal instruction file still tracked by git?
- narrow "still in your last commit": Was removal of the personal instruction file committed?
- narrow "No committed `.gitignore`": Does a shared ignore rule cover the personal file?
- narrow "keeps `CLAUDE.local.md` from being ignored": Does a later exception cancel the personal-file ignore rule?
- narrow "Only `.git/info/exclude`": Is the ignore rule committed for your teammates too?
- narrow "but that rule isn't committed": Have you committed the personal-file ignore rule?
- narrow "still holds a note that is only yours": Did a personal path or global habit remain in the team file?
- back: Y1 Revisit the decision and evidence from this step before trying the same action again.
