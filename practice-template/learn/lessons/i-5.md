## intro
- minutes: "about 20 minutes"
- why: "Claude sometimes stops while the tests fail: send it back to work when it does, in every session."
- can: "enforce a rule with a hook that fails closed, and send Claude back to work when it stops while your tests fail."
- payoff: "enforce a rule with a hook that fails closed, and send Claude back to work when it stops while your tests fail."
- read: "[Hooks reference](https://code.claude.com/docs/en/hooks): every event, its input and its output."
- need-repo: "The repository from [lesson 4](04-permissions-and-sandbox.md), with its `.claude/settings.json` and a test command, and your copy of the practice template with Node.js LTS: the check runs from the copy."
- need: "`jq`, which the hook scripts use, and `python3`, which `format-after-edit.sh` uses."

- say: Done when the skeleton is saved.
