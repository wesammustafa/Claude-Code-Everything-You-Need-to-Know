## ladder

### the committed `.mcp.json` runs chrome-devtools-mcp at an exact version, with usage statistics, CrUX lookups and update checks off
- narrow "is not committed. Run": Does git status still list .mcp.json as new or changed?
- narrow "There is no .mcp.json at the repository root": Is the file saved at the root of the folder the check reads?
- narrow "is not valid JSON": Is a comma, a quote or a bracket missing, or one too many?
- narrow "No server in .mcp.json runs chrome-devtools-mcp": In the committed file (git show HEAD:.mcp.json), does one of the server's args name the chrome-devtools-mcp package?
- narrow "isn't pinned. Name an exact version": In the committed file (git show HEAD:.mcp.json), does the package end in @ and a version of three numbers, not a tag?
- narrow "Usage statistics are still on": In the committed file (git show HEAD:.mcp.json), do the args hold the flag that turns off usage statistics?
- narrow "Performance traces can still send URLs": In the committed file (git show HEAD:.mcp.json), do the args hold the flag that turns off CrUX lookups?
- narrow "Update checks are still on": In the committed file (git show HEAD:.mcp.json), does the server's env set the variable that turns off update checks?
- hint: "The committed `.mcp.json` pins the package to an exact version and turns off usage statistics, CrUX lookups and update checks"
- hint: "If the server item fails, compare each argument with the Worked example's command: `@latest` isn't pinned."
- back: Y2 Review the shared configuration.
