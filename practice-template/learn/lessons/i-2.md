## ladder

### a committed CLAUDE.md imports a file with `@path`, and the file exists
- narrow "There is no committed CLAUDE.md": Is CLAUDE.md committed in the folder the check reads?
- narrow "has no @path import outside backticks": Did you commit CLAUDE.md after you added the import, and is the import outside backticks?
- narrow "doesn't exist. An import path runs until the first space": Does the imported file exist, and does a period or comma follow its path?
- hint: "The committed `CLAUDE.md` imports a file that exists: `git show HEAD:CLAUDE.md | grep '@'` shows the import."
- hint: "If the import check fails, look for punctuation right after the path, or a path written relative to the wrong folder: an import resolves from the file that holds it."
- back: W1 Compare the saved import with the file's real path.

### a committed rule in `.claude/rules/` is scoped with `paths:`, and every scoped rule matches a file in the repository
- narrow "has `paths:` frontmatter. Scope a rule": Are your rules committed, and does each one open with its paths frontmatter?
- narrow "which matches no file in the repository": Is the rule's pattern written from the project root, with each folder spelled as git lists it?
- hint: "If a rule matches no file, its pattern is relative to the project root, so `source/**` matches nothing in a project whose code is in `src/`."
- bottom: "git ls-files ':(glob)<pattern>'"
- back: Y4 Check the fixed rule before the commit.

### `.practice/i-2-loaded.txt` shows the imported file and a scoped rule loading
- narrow "There is no load log": Did you start the session with the hook file, in the folder the check reads?
- narrow "The log has no `include` line": Is the import's path right, and did the session start with the hook file?
- narrow "The log shows no scoped rule loading": Did Claude read a file that a committed rule's pattern matches, from the project root?
- hint: "If the log has no `path_glob_match` line, start the session with `--settings .practice/i-2-hook.json` and check that the pattern, read from the project root, matches the file Claude read."
- bottom: "grep -E '^(include|path_glob_match)' .practice/i-2-loaded.txt"
- back: Y4 Repeat the source read in a fresh logged session.
