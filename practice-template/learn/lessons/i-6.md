- narrow "The frontmatter name is": Does the committed frontmatter's name line say test-gaps?

### its `tools` list only reads code: no tool that edits files, runs commands or reaches the web
- narrow "is not committed. Run": Does git status still list the subagent file as new or changed?
- narrow "There is no .claude/agents/test-gaps.md": Is the file saved at that path in the folder the check reads?
- narrow "Fill in `tools:`": Does the committed file still say tools: TODO, or have no tools line at all?
- narrow "would let it change files or run commands": Does the tools line name a tool that edits files or runs commands?
- narrow "reaches the web": Does the tools line name a web tool that reading your code never needs?
- hint: "Its tools only read code: the `tools` line names tools such as `Read`, `Grep` and `Glob`, and no tool that edits files, runs commands or reaches the web, such as `Edit`, `Bash` or `WebFetch`."
- hint: "If the tools item fails, remove each tool that can change files, run commands or reach the web; without a `tools` line, a subagent gets every tool."
- back: Y1 Limit the tools to the reporting task.
