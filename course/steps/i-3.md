## ladder

### the committed changelog skill runs a smaller model at low or medium effort
- narrow "is not committed. Run": Does Git still list the completed skill as uncommitted?
- narrow "There is no .claude/skills/changelog/SKILL.md": Is the skill saved at that path in the repository the check reads?
- narrow "Set `model:` in the skill": Does the committed file still have a TODO on its model line?
- narrow "picks a larger model than this task needs": What do a precise input and a short output you will review need?
- narrow "isn't a model alias or name": Is the model line an alias, such as haiku, spelled as the lesson gives it?
- narrow "Set `effort:` to one of": Does the committed file still have a TODO or misspelled effort level?
- narrow "asks for a higher effort than a routine": Does this reviewed entry need the diagnostic task's effort?
- bottom: "git show HEAD:.claude/skills/changelog/SKILL.md | grep -E '^(model|effort):'"
- back: Y2 Review the routine task's settings here.

### a committed CHANGELOG.md has an entry under `## Unreleased`
- narrow "There is no committed CHANGELOG.md": Did the commit include CHANGELOG.md, or only the change and the skill?
- narrow "has no `## Unreleased` heading": Does the committed changelog have the Unreleased heading?
- narrow "in CHANGELOG.md has no entry": Is the new list item under Unreleased rather than an older release?
- hint: "If there's no entry, stage a change before you run `/changelog`, because the skill reads only staged changes."
- bottom: "git show HEAD:CHANGELOG.md"
- back: Y3 Review the staged change and its entry here.
