## ladder

### a committed workflow runs `anthropics/claude-code-action` pinned to a release or a commit SHA, in automation mode, with its credential from a secret and none in the file
- narrow "There is no committed workflow that runs": Is the workflow file in a commit yet?
- narrow "isn't committed. Run `git add": Did you add the new file before you committed?
- narrow "but that change isn't committed": Is your latest edit to the workflow committed?
- narrow "You need a second workflow": Is the committed workflow the one you start by hand, or one that waits for a mention?
- narrow "runs Claude with a `prompt`, but": Does the workflow start by hand, and on nothing else?
- narrow "holds what looks like a Claude API key": Did a credential end up in the file itself?
- narrow "without a version": Does the line that names the action say which release to run?
- narrow "is a short commit SHA": Is the commit you pin written out in full?
- narrow "can move to a new release": Does the pin name one release, not a tag that moves?
- narrow "so Claude waits for": Does the step give Claude its task, so it runs as soon as the workflow starts?
- narrow "is empty. Write what Claude should do": Does the task you give Claude say what to do?
- narrow "passes no credential": Does the step hand the action its credential?
- narrow "isn't read from a secret": Does the credential come from the repository secret?
- narrow "Remove `pull_request_target`": Does the workflow start on anything besides your own manual run?
- hint: "If the first or second item fails, its hint names the line or the limit to fix."

### its limits are in the file: `--max-turns` of at most 10, an `--allowedTools` list without unrestricted `Bash`, a read-only job token and `timeout-minutes`
- narrow "There is no committed workflow that starts on": Is a workflow you start by hand committed yet?
- narrow "has no `claude_args`, so nothing limits": Does the step pass any limits to Claude Code?
- narrow "An unquoted `#` in `claude_args`": Does a note inside the limits hide the flags after it?
- narrow "not `--max-turns=": Is the turn limit written as two words?
- narrow "sets no turn limit": Does the step cap the turns, spelled as the page spells it?
- narrow "has no number after it": Does a number follow the turn limit?
- narrow ": use a number from 1 to 10": Is the turn limit a whole number from 1 to 10?
- narrow "as separate words": Is each tool rule in quotes?
- narrow "which lets Claude run any command": Does the tool list allow only the link-check command?
- narrow "pre-approves no tool": Does the step allow the one command Claude needs?
- narrow "lists no tool:": Does the tool list name a tool?
- narrow "sets no `timeout-minutes`": Does the job stop after a time you chose?
- narrow "`timeout-minutes: ": Is the job's time limit a whole number from 1 to 30?
- narrow "Neither the workflow nor the job": Does the workflow say what its job token may do?
- narrow "write access to everything": Does the job token get only read access?
- narrow "and this job only reads": Which permission still grants write access?
- narrow "passes no `github_token`": Does Claude act with this job's own token?
- narrow "isn't this job's own token": Is the token Claude gets this job's own?
- hint: "If the first or second item fails, its hint names the line or the limit to fix."

- narrow "yet. Once your run finishes": Did you save the run list in this new copy?
- narrow "isn't JSON": Did you save the list with the JSON flag, unchanged?
- narrow "lists no runs.": Did the run start before you saved the list?
- narrow "doesn't hold the fields": Does the saved list carry the fields the check reads?
- narrow "has no GitHub run URL": Does the saved list carry each run's address?
- narrow "but this repository's `origin` is": Did you save the list in the new copy the run belongs to?
- narrow "hasn't finished": Did the run end before you saved the list?
- narrow "ended with": Did the run succeed, or does its log say what to fix?
- narrow "has no `headSha`": Does the saved list say which commit the run used?
- narrow "which this repository doesn't have": Did you pull the commit the run used?
- narrow "Once your workflow is pushed": Did you run the workflow after you pushed it?
- narrow "lists only runs that `@claude` started": Did you start your own workflow, not one that answers mentions?
- narrow "lists no run started by hand": Did you start the workflow by hand?
